STAR RADIO

Διαχείριση χειροκίνητων εξωφύλλων

Μεταφόρτωσε εικόνα και καταχώρισε την αντιστοίχιση καλλιτέχνη–τίτλου. Η εικόνα αποθηκεύεται στον φάκελο covers/ και ενημερώνεται το covers.json, ώστε να εμφανιστεί στον player.

1. Σύνδεση GitHub

Χρειάζεται πρόσβαση μόνο στο repository star-radio/star-radio με δικαίωμα Contents: Read and write. Το token μένει μόνο στη μνήμη αυτής της σελίδας και δεν αποθηκεύεται. Μην το στείλεις σε κανέναν.

Αν δεν έχεις token, δημιούργησε ένα από τις ρυθμίσεις Fine-grained tokens του GitHub. Επίλεξε repository star-radio/star-radio και Repository permissions → Contents → Read and write.

2. Στοιχεία εξωφύλλου

Δεκτά JPG, PNG ή WEBP, έως 8 MB. Το όνομα δημιουργείται αυτόματα από καλλιτέχνη και τίτλο.
